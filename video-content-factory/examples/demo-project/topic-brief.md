# 选题简报：AI 口播视频自动化生产线

- **选题一句话**：给口播视频创作者演示如何把「选题 → 稿件 → 录制 → 剪辑 → 特效 → 发布」压缩成两阶段闭环，让单条视频制作时间从 3 小时降到 20 分钟以内。
- **目标平台**：B站（主平台，横屏 16:9）；视频号/抖音（衍生竖屏 9:16，可后续裁切）。
- **目标受众**：独立开发者、AI 工具博主、知识 IP、需要稳定产出口播视频的小团队。
- **发布时机**：`video-content-factory` Skill 正式上线后，作为官方示例工程同步放出，用于展示阶段 1 产物形态。
- **核心冲突**：创作者 80% 的精力耗在剪辑、特效、字幕、封面等重复劳动上，而不是内容创作本身。
- **一句话钩子**：你还在为一条口播视频剪满 3 小时？
