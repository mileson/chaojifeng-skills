## 安装

在 Claude Code 中运行对应 skill 的安装命令：

```
/install-skill https://github.com/mileson/chaojifeng-skills/tree/main/offboarding-handover
/install-skill https://github.com/mileson/chaojifeng-skills/tree/main/skill-creator
```

也可以直接进入下方 skill 条目，复制对应安装地址使用。

## Skills 一览

### offboarding-handover — 离职交接资料整理

帮助离职员工把杂乱的工作资料整理成结构化的交接包。

- 支持可配置的分类规则，适配不同行业
- 自动生成 HTML 可视化入口页面
- 输出可打包交付的 ZIP 文件
- 多 Agent 协作：资料盘点、缺失检测、项目映射、风险检查

适用场景：离职员工梳理零散工作资料、搭建交接目录、生成可视化入口。

安装地址：
`/install-skill https://github.com/mileson/chaojifeng-skills/tree/main/offboarding-handover`

### skill-creator — Skill 创建与更新工作流

帮助创建新 Skill、更新现有 Skill，并把 `SKILL.md`、`references/`、`examples/`、`scripts/` 和模板组织成稳定可复用的结构。

- 内置创建前确认流程，先对齐目标再落地
- 支持用 Mermaid 流程图表达新增、修改、风险与保留项
- 覆盖 frontmatter、目录结构、示例、脚本和持久化记忆设计
- 提供初始化、快速校验和 Mermaid 渲染辅助脚本

适用场景：新建 Skill、重构 Skill 结构、补规范、拆 references、整理模板和脚本。

安装地址：
`/install-skill https://github.com/mileson/chaojifeng-skills/tree/main/skill-creator`
