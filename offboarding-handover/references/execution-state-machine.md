# 执行状态机

使用本参考把 offboarding-handover skill 当作分阶段工作流运行，而不是开放式对话。

目标是首轮运行的正确性。

本 skill 应表现得像一个小型工作流引擎：

- 每个阶段有进入条件
- 每个阶段有必需产出
- 每个阶段有不可跳过规则

## 核心原则

不要为对话自由度做优化。

要为以下目标优化：

- 首轮执行正确
- 低遗漏风险
- 稳定的交接输出质量

## 状态机

### Phase 0 — 环境检测

必需动作：

- 确定工作目录
- 检测 `.offboarding-handover/` 是否存在
- 检测输出目录是否存在
- 判断是首次运行还是刷新/更新

退出条件：

- 执行模式确定为 `first_run` 或 `refresh`

不可跳过：

- 不要仅因存在一些文件就假设是刷新
- 不要仅因输出缺失就假设是首次运行

### Phase 1 — 清单基线

必需动作：

- 统计文件总数
- 统计目录总数
- 列出有效的顶层分支
- 统计各分支文件数
- 汇总扩展名分布

退出条件：

- 清单基线可用

不可跳过：

- 清单存在之前不得向用户提问
- 清单存在之前不得深度分类

### Phase 2 — 触发检查

必需动作：

- 应用硬触发规则
- 决定 `single_agent` 还是 `parallel_subagent`

硬触发条件：

- `total_files > 3000`
- `meaningful_top_level_branches > 8`
- 内部资料 + 客户/项目资料 + 风险/合规信号同时出现
- 角色置信度不高

退出条件：

- 本轮执行模式锁定

不可跳过：

- 不得把已触发的文件夹重新解读为“足够简单”
- 不得用主观判断绕过已触发的并行运行

### Phase 3 — 并行子代理扇出

仅当 Phase 2 选择了 `parallel_subagent` 时需要。

必需动作：

- 显式宣布将要启动的子代理
- 在清单 worker 之外至少启动 2 个专职子代理
- 分配互不重叠的职责

优先子代理：

- `offboarding-role-detector`
- `offboarding-project-mapper`
- `offboarding-risk-checker`
- `offboarding-missing-facts-detector`

退出条件：

- 子代理发现已返回

不可跳过：

- 只有一个清单子代理是不够的
- 专职子代理返回之前不得向用户提问
- 综合分析之前不得生成产出

### Phase 4 — 综合分析与覆盖率检查

必需动作：

- 合并子代理发现
- 对照清单检查覆盖率
- 识别缺失的关键事实

退出条件：

- 协调者掌握：
  - 可能的角色
  - 可能的行业
  - 可能的项目/客户划分
  - 可能的风险画像
  - 一份最小问题清单

不可跳过：

- 综合分析之前不得生成产出
- 更小的问题集足够时，不要问宽泛问题

### Phase 5 — 询问用户

必需动作：

- 问最少量的高价值问题
- 补齐关键的人员/日期/状态缺口
- 避免证据已经回答过的冗余问题

退出条件：

- 回答状态足以生成第一版精修 HTML

不可跳过：

- 综合分析之前不得提问
- 不要问超出需要的问题

### Phase 6 — 渲染

必需动作：

- 更新配置
- 更新回答
- 构建 manifest
- 渲染 markdown
- 渲染 HTML
- 清理空目录

退出条件：

- 交接包已生成

不可跳过：

- 关键事实仍缺失时，不得从不完整状态渲染

### Phase 7 — 刷新模式

仅用于后续运行。

必需动作：

- 检查缺失事实
- 只针对未解决事项提问
- 重新渲染产出

退出条件：

- HTML 和 markdown 已刷新

不可跳过：

- 除非信任/重扫规则要求，不要重跑繁重的首次扫描逻辑

## 强执行规则

某个阶段未完成时，代理不得悄悄进入后续阶段。

尤其是：

- 无清单 → 不得询问用户
- 命中硬触发 → 不得单线程继续
- 无综合分析 → 不得生成

## 推荐话术模式

代理应让阶段切换可见。

例如：

- `Phase 1 完成：清单基线就绪。`
- `Phase 2 已触发并行子代理模式。`
- `Phase 3：现在启动 offboarding-role-detector、offboarding-project-mapper、offboarding-risk-checker、offboarding-missing-facts-detector。`
- `Phase 4 完成：发现已综合，准备定向提问。`
- `Phase 6：渲染最终交接包。`
